# План реализации: Древовидная панель навигации по датам (Проводник папок)

## Обзор задачи
Добавить слева вверху плавающую панель с иконкой папки, которая открывает древовидный проводник дат (Год -> Месяц -> День). При выборе папки отображается отфильтрованный список фото/видео за эту дату, а иконка меняется на «Назад» для возврата.

## Архитектура и компоновка

### 1. Плавающая левая кнопка («Папка» / «Назад»)
- Находится в левом верхнем углу (`Alignment.TopStart`).
- В обычном режиме показывает иконку папки (`R.drawable.folder`).
- При открытом проводнике или активном фильтре даты меняется на стрелку назад (`R.drawable.arrow_back`).
- Синхронно смещается с верхней панелью (`topbarOffset`).

### 2. Древовидный проводник дат (`DateFolderTreeView.kt`)
- Формирует иерархическое дерево папок из `images`:
  - **Уровень 1**: Год (например, `2026`).
  - **Уровень 2**: Месяц (например, `Июль`).
  - **Уровень 3**: День (например, `28 число`).
- Каждая папка имеет иконку стрелочки/плюсика слева для разворачивания и сворачивания подпапок.
- При нажатии на любую папку (Год, Месяц или День) выбирается соответствующая дата, закрывается проводник и показывается список снимков за этот период.

### 3. Фильтрация и навигация в `ImageListViewModel.kt`
- Внедрить состояние `dateFilter` (выбранный Год, Месяц, День).
- При активном `dateFilter` список `filteredImages` отбирает только снимки выбранного периода.
- При нажатии на кнопку «Назад» `dateFilter` сбрасывается, проводник закрывается, и возвращается полный главный список.

- Сборка проекта через Gradle (`app:assembleDebug`).
- Ручная проверка:
  1. Нажать на иконку папки слева вверху — открывается дерево Год -> Месяц -> День.

  3. Иконка меняется на стрелку «Назад» — при клике происходит возврат к целому списку.
