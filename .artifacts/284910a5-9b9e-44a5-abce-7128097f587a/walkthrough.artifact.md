# Отчет о выполнении: Сохранение свайпнутой даты при возврате из просмотра фото

## Что было сделано

1. **Защита состояния `activeDateFilter` от сброса при перекомпоновке (`DateView.kt`)**:
   - В `DateView.kt` обновлен блок `LaunchedEffect(year, month, day)`.
   - Теперь начальная дата из аргументов маршрута устанавливается только тогда, когда `activeDateFilter` ещё не был задан (`model.activeDateFilter.value == null`).
   - При свайпе списка на соседнюю дату и последующем клике на фотографию `activeDateFilter` зафиксирован на новой выбранной дате. При закрытии просмотрщика полноэкранного слайдера по кнопке «Назад» фильтр даты больше **никогда не сбрасывается** на старую начальную дату входа.
