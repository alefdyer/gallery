# Отчет о выполнении: Фиксация экземпляра задачи через launchMode=singleTask

## Что было сделано

1. **Единый синглтон задачи (`AndroidManifest.xml`)**:
   - Установлен параметр `android:launchMode="singleTask"` для `MainActivity`.
   - Теперь при повторных нажатиях на иконку Галереи из лаунчера или возврате из сторонних приложений (Камеры) система Android не перезапускает активность через `onCreate`, а активизирует один и тот же постоянно живущий экземпляр задачи.

2. **Обработка повторных вызовов (`MainActivity.kt`)**:
   - Переопределен метод `onNewIntent(intent)`, позволяющий принимать повторные интенты без перезапуска интерфейса и сброса открытых экранов.

## Результаты проверки
- Проект успешно собран с помощью Gradle (`app:assembleDebug`).
